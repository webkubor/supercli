      这份排行怎么算？

      目录数据 · llms.txt

      “厂商官方”表示由产品或平台厂商直接维护；“社区项目”表示由独立作者、开源组织或社区维护，也包括项目自身的原版 CLI。两者只区分来源，不代表质量或可信度高低。

      默认按所关联 GitHub 仓库的累计 Stars 降序，同分按名称排列。Stars 表示仓库关注度，不代表 CLI 用户数、下载量或质量评分。

      Wrangler（workers-sdk）、Vercel 等项目的数据覆盖整个仓库。界面提供快照时间，仓库归档状态会在详情里标注。仓库最近更新以 GitHub pushed_at 为准。

      收录厂商官方 CLI 与社区项目。没有可比 GitHub 仓库的工具展示“未计分”，列在有数据条目后。PR 由维护者本地核验、手动合并。

      下载量来自 npm 官方下载 API 的最近 30 个可用日，包含重复下载、CI 与依赖安装，不等于用户数或 CLI 执行次数。仅覆盖目录安装命令对应的 npm 包，未接入的工具不会按零处理；下载排序只比较有数据条目。

      仓库更新时间是 GitHub pushed_at，表示作者或维护者最近向仓库推送的时间，不等于最新版本发布时间；monorepo 可能包含其他工具的改动。真实调用量目前没有统一公开数据源。
