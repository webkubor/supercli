# 项目来源标记

`maintainerType` 是人工审核字段，不按 Stars、下载量、许可证或用户安装情况推断。

- `vendor` / 厂商官方：产品或平台厂商直接维护的 CLI，结合目录中的厂商、文档和仓库归属核对。例如 Cloudflare Wrangler、腾讯云 CLI、OpenAI Codex。
- `community` / 社区项目：独立作者、开源组织或社区维护，包括项目自己的原版工具，例如 ripgrep、Git、FFmpeg。不是“非官方”或“低质量”的同义词。

贡献 PR 必须提供文档或维护者仓库作为依据；不明归属应先核验，不强行猜测。来源筛选不会改变排序的统计口径。`locallyInstalled` 仅为历史收录记录，线上不显示或据此筛选。旧 `local=1` URL 自动归一化为全部来源。
